# 🚀 QUICK START GUIDE

## 1️⃣ Start Server
```
node server.js
```
Server runs on: http://localhost:3001

## 2️⃣ Login
```
Username: admin
Password: admin123
```

## 3️⃣ Add Coupon
1. Click "Coupon Manager"
2. Fill form with coupon details
3. Click "Add Coupon"
4. ✅ Check dashboard - coupon count updates

## 4️⃣ Add Item
1. Click "Item Manager"
2. Fill form with item details
3. Click "Add Item"
4. ✅ Check dashboard - item count updates

## 5️⃣ Check Status
1. Go to Dashboard
2. Scroll down to "System Status" section
3. See:
   - Coupons added (active vs inactive)
   - Items added
   - Overall system status

## If Login Doesn't Work

1. Check server is running - should see:
   ```

   ✅ Database connected successfully
   ```

2. Open browser console: F12 → Console tab
3. Look for error messages
4. Try admin/admin123 again
5. If still fails, restart server
